# REPORT ON REACT APPLICATION

## 1. Introduction

React is a popular **JavaScript library used for building user interfaces and web applications**. It was originally developed by Facebook, now known as Meta, and is widely used by developers to create interactive and responsive websites.

React allows developers to divide a web application into small, reusable parts called **components**. Instead of writing one large piece of code, developers can create separate components and combine them to form a complete application.

React is mainly used for developing **front-end applications**, especially modern web applications that need to respond quickly to user actions.

## 3. What is React?

React is an **open-source JavaScript library for building user interfaces**.

Unlike traditional websites where an entire page may reload when information changes, React can update only the part of the page that needs to change. This makes applications feel faster and more interactive.

For example, in a shopping application, when a user adds an item to a shopping cart, React can update the cart information without requiring the entire page to reload.

---

## 4. Features of React

React has several important features.

### 4.1 Components

Components are the building blocks of a React application.

A component can represent a part of a webpage, such as:

* Header
* Navigation bar
* Login form
* Product card
* Footer
* Button

Components can be reused in different parts of an application.

### 4.2 JSX

React commonly uses **JSX**, which allows developers to write HTML-like code inside JavaScript.

Example:

```jsx
function Welcome() {
    return <h1>Welcome to my React Application</h1>;
}
```

JSX makes it easier to describe what the user interface should look like.

### 4.3 Virtual DOM

React uses a **Virtual DOM** to efficiently update the user interface.

When data changes, React determines which parts of the interface need to be updated instead of unnecessarily reloading the entire page.

### 4.4 Reusable Components

Components can be created once and reused many times.

For example, a `ProductCard` component can be used to display many different products.

### 4.5 State

**State** is information that can change while an application is running.

Examples include:

* Number of items in a shopping cart
* Username
* Login status
* Counter value
* Form information
